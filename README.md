## 📖 项目简介

系统性介绍古今中外重要哲学家的生平、思想、作品和对后世影响的开源项目。目前已收录 **48 位**哲学家条目，涵盖存在主义、分析哲学、古希腊哲学、中国哲学、政治哲学等多个流派。

## 🚀 快速访问

项目使用 **Zensical** 构建，在线站点：

👉 **[https://GTX950L.github.io/philosopher-encyclopedia/](https://GTX950L.github.io/philosopher-encyclopedia/)**

## 📂 仓库结构

| 目录/文件 | 说明 |
|-----------|------|
| `content/` | 站点内容目录（MkDocs docs_dir） |
| `content/philosophers/` | 哲学家条目页（共 48 篇） |
| `content/docs/` | 补充资料（哲学流派、时间线） |
| `content/README.md` | 项目首页（站点首页源文件） |
| `mkdocs.yml` | 站点配置 |
| `.github/workflows/` | CI/CD 工作流（自动部署到 Pages） |

## 🧭 推荐学习路径

项目按**最适合学习哲学**的顺序排列，从存在主义入门，逐步扩展到分析哲学、古希腊哲学、中国哲学和政治哲学。详见[在线站点](https://GTX950L.github.io/philosopher-encyclopedia/)首页的推荐阅读顺序。
