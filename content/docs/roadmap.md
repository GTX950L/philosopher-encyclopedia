## 收录流程（Checklist）

- [ ] 按 [template.md](../template.md) 撰写条目（基本信息表 / 生平时间线 / 核心思想 / 代表作品 / 影响 / 名言 / 延伸阅读）
- [ ] 文件命名：全小写拼音或英文名，如 `weber.md`、`zhuxi.md`
- [ ] frontmatter 添加 3-4 个 tags（流派 / 时代 / 地域）
- [ ] 在 `mkdocs.yml` nav 中注册（选择合适的"阶"或"参考"位置）
- [ ] 运行 `python scripts/gen_index.py` 校验（必需章节 + nav 注册 + 链接一致性）
- [ ] 运行 `python scripts/gen_pinyin_index.py` 刷新拼音索引
- [ ] 去掉其他条目中该人物链接的"（尚未收录）"标注
- [ ] PR 提交，CI 自动校验
